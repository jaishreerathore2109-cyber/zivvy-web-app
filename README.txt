Zivvy online starter.
1) Create a Supabase project.
2) Run supabase.sql in Supabase SQL Editor.
3) Put the Supabase project URL and browser publishable/anon key into config.js.
4) Test locally with Live Server.
5) Deploy the folder to Netlify.
Never put a Supabase service_role/secret key in config.js.
The starter currently includes real email auth, profiles, posts, search and the database tables for follows, likes, comments and messages. Those latter UI features can be wired next.
